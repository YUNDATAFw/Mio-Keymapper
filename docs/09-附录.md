# 09 附录

**本章定位**：全书唯一权威总表——事件枚举、**入口函数全集**、模块↔桥↔源文件索引、常量速记。正文只引用本章，不重复维护。

## A. 宿主事件枚举（ShortcutEventType）

| 枚举 | 中文名 | 触发时机 | 是否进 DSL |
|---|---|---|---|
| `REGISTER` | 注册 | 快捷键注册 | 否（传统动作） |
| `UNREGISTER` | 反注册 | 快捷键移除 | 否 |
| `KEY_ON` | 开关开启 | SWITCH 翻转开 | 是（激活） |
| `KEY_OFF` | 开关关闭 | SWITCH 翻转关 | 是（失活） |
| `KEY_PRESS` | 快捷键按下 | 全模型按下瞬间 | 是（BUTTON 驱动 / 全模型手势） |
| `KEY_RELEASE` | 快捷键松开 | 全模型松开瞬间 | 是 |
| `BUTTON_PRESS` | 按钮按下 | 仅 BUTTON 模式 | 是（BUTTON 驱动） |
| `BUTTON_RELEASE` | 按钮松开 | 仅 BUTTON 模式 | 是 |
| `PRESSURE_PLATE_PRESS` | 压力板按下 | 压力板达标 | 是（激活） |
| `PRESSURE_PLATE_RELEASE` | 压力板松开 | 压力板松手 | 是（失活） |
| `PRESSURE_PLATE_LONG_PRESS` | 压力板长按 | **未发出（仅定义）** | — |
| `ENGINE_START` | 引擎启 | 引擎启动 | 否（传统） |
| `ENGINE_STOP` | 引擎停 | 引擎停止 | 否 |
| `SHORTCUT_BAR_SHOW` / `SHORTCUT_BAR_HIDE` | 快捷键条显/隐 | 浮层显隐 | 否 |

> 这是**快捷键**事件。另有 **WS 侧 29 个联动事件**（`onPlayerChat`/`onGameStart`/…，原始 JSON 入参）——列表见 [10 §10.4](10-WS服务与游戏联动.md)。

## B. 各模型「按下→松开」事件序列

| 模型 | 按下 | 松开/关闭 |
|---|---|---|
| BUTTON | `KEY_PRESS`+`BUTTON_PRESS` | `KEY_RELEASE`+`BUTTON_RELEASE`（拖出立即补松） |
| PRESSURE_PLATE | `KEY_PRESS` →（阈值达标）`PRESSURE_PLATE_PRESS` + 激活 | 未达标：仅 `KEY_RELEASE`；达标：`KEY_RELEASE`+`PRESSURE_PLATE_RELEASE`+失活（可带释放延时） |
| SWITCH | 仅 `KEY_PRESS` | `KEY_RELEASE` + 翻转 `KEY_ON`/`KEY_OFF` + 激活/失活 |

## C. DSL 插件可导出入口全集

按**声明的 service tag** 分区。宿主只调用与声明对应的入口；未声明的 tag 对应入口**永不执行**。

### C-1 包级（`MAINSERVICE`）

| 入口 | 必/可选 | 触发条件 |
|---|---|---|
| `loading()` | 必（服务存在时） | 包打开时调用一次 |

### C-2 快捷键（`SHORTCUT_KEY`）

| 入口 | 必/可选 | 触发条件 |
|---|---|---|
| `keyInit()` | 必 | 服务线程启动首调 |
| `onTriggerDown()` | 必 | 任何模型激活（按/开/达标） |
| `onTriggerUp()` | 可选 | 真实松开/关闭后（紧接 onTriggerDown 返回） |
| `onButtonPress()` / `onButtonRelease()` | 可选 | 仅 BUTTON 模型 |
| `onSwitchOn()` / `onSwitchOff()` | 可选 | 仅 SWITCH 模型 |
| `onPressurePlatePress()` / `onPressurePlateRelease()` | 可选 | 仅 PRESSURE_PLATE 模型 |

### C-3 配置页（`CONFIG`）

| 入口 | 必/可选 | 触发条件 |
|---|---|---|
| `schema()` | 必 | 宿主开配置页收集声明（[11](11-配置页与HostData.md)） |
| `onButton(String key)` | 可选 | 用户点击 `MioConfig.onButton` 登记的按钮 |

> 旧式兼容：`values()`（回显）与 `schema()` 返回 `List<Map>` 仍受支持，新插件免写。

### C-4 WS 服务（`WS_SERVICE`）

| 入口 | 必/可选 | 触发条件 |
|---|---|---|
| `serverInit()` | 必 | WS 服务线程启动首调（注册 `registerFeature` 也在此） |
| `on<事件名>(String json)` | 可选（按需导出） | 对应 WS 事件到达，入参原始 JSON；**事件名 = 宿主事件去前缀**（[10 §10.4](10-WS服务与游戏联动.md)） |
| `onWsFeatureToggle(String key, Bool enabled)` | 可选 | 悬浮窗功能开关被切换 |

### C-5 生命周期与工具（全类型插件通用）

不依赖 service tag，任何插件导出即可被宿主按事件回调；**未导出则静默跳过**（`callIfExported`）。

| 入口 | 触发条件 |
|---|---|
| `onStart()` | 悬浮窗服务加载插件、其全部服务线程启动后调用一次 |
| `onEnable()` | 插件页启用开关打开、悬浮窗运行中重载后调用 |
| `onDisable()` | 插件页禁用开关关闭时，句柄关闭前调用 |
| `onUninstall()` | 插件页删除插件确认后，关句柄/引擎卸载前调用 |
| `checkUpdate()` → `Object` | 插件页「检查更新」按钮触发（后台线程，内部可联网）。返回 JSON 字符串或 Map `{hasUpdate, version, versionCode, url, description}`；未实现返回 `null`。宿主解析后弹窗，用户点「下载」→ `DownloadManager.addTask(url, 文件名)` |

### C-6 扩展入口（接线状态一览）

| 入口 | 状态 |
|---|---|
| `onEngineStart()` / `onEngineStop()` | **已接线**：引擎启停（`ShortcutKeyDispatcher` 获取/释放执行器）时分发到所有已打开插件（`callIfExported`，未导出跳过） |
| `onKeyOn` / `onKeyOff` | **已接线**：外接键鼠监听引擎（`InputMonitorEngine`，见 §F）每次实体键按下/松开广播到所有插件，参数为 Android 键名全称（`"KEYCODE_F6"`）；链路与语义见 [05 §5.3.1](05-事件系统与触发模型.md) |
| `onTriggerAxis` / 带参手柄事件 | 无事件源，勿依赖 |

## G. 兼容性说明

- 本文档对应 **Mio 工程当前代码**与插件工程 `Desktop\开发\Plugin` 同一版本（引擎版本 `4`）。
- 随 Mio APK 升级，桥签名可能增补；以插件工程 `src/script/mio/utils/*.dsl` 与 `mio/ws/MioWs.dsl` 为「当前真相源」，宿主侧对表本文 §D。
- 未接线入口（附录 C-5 的保留项）不代表未来必有，开发请勿依赖。
- 旧式兼容（`schema()` 返回 `List<Map>`、`values()` 回显）见 [11 §11.8](11-配置页与HostData.md)。
